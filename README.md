# Second Harvest — «Второй урожай» (тестовая веб-сборка)

**Играть:** https://denbogdanov1998-design.github.io/SecondHarvest-play/

Игра про автоматизацию фермы после пожара: ручной труд → механизмы → промышленная ферма.
Ранняя версия для теста друзьями — отзывы пишите автору или в Issues этого репозитория.

## Управление
- **WASD / стрелки** — ходить, **колесо** — зум, **ЛКМ** — действие инструментом рядом с фермером
- **[1]** мультитул (добыча, расчистка гари, сбор урожая) · **[2]** посев в теплице · **[3]** лейка
- **TAB** — карманы и постройки (открыть рецепт → создать → поставить)
- **E** у постройки — её панель · **M** — карта мира · **Esc** — меню
- Наведи курсор на клетку — подсказка

## Нужно знать
- Компьютер с клавиатурой и мышью; телефоны не поддерживаются.
- Первая загрузка ~30–40 МБ.
- Сохранение — в браузере (автосохранение раз в минуту и при уходе со вкладки). Очистка
  данных сайта или другой браузер — новая игра.

Здесь только собранная игра; исходники — в приватном репозитории.
Графика: [Kenney](https://kenney.nl) Tiny Town и Tiny Farm (CC0).
